本地啟動 Web Orchestrator
1

Clone 專案並安裝套件

git clone https://github.com/yoshiagent/stock-analysis-report.git
cd stock-analysis-report
pip install -r requirements.txt
2

啟動 Web Orchestrator（自動開啟瀏覽器）

python -X utf8 web_app.py
3

輸入股票代碼或名稱，一鍵分析

http://localhost:5001
